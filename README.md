## 📌 Project Overview

The **TO-DO LIST (TKINTER GUI)** is a Python-based desktop application designed to help users organize and manage their daily tasks efficiently.

Users can add tasks, view their tasks, mark tasks as completed, and delete tasks using a simple graphical user interface.

## ✨ Features

- ➕ Add new tasks
- 📋 View all tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🖥️ Simple and interactive GUI
- 🐍 Developed using Python
- ⚡ Lightweight and easy to use

## 🛠️ Technologies Used

- **Python**
- **Tkinter**
- **GUI Programming**

Tkinter is Python's standard GUI library and is used to create the application's graphical interface.

## ⚙️ How It Works

1. Launch the application.
2. Enter a task in the input box.
3. Click the **Add Task** button.
4. The task is displayed in the task list.
5. Select a task to mark it as completed.
6. Delete tasks that are no longer required.
